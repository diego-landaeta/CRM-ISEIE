# De donde sale lo visual de esta pantalla

Ninguna de estas piezas se diseño aqui.

## `fondo-whatsapp.png`

Del repositorio **yuvraj24/WhatsApp-Clone**, licencia **MIT**
https://github.com/yuvraj24/WhatsApp-Clone — `web-client/src/assets/images/WhatsappBG.png`

Es el fondo de patron del hilo de conversacion.

## La estructura del chat

**@chatscope/chat-ui-kit-react**, licencia **MIT**
https://github.com/chatscope/chat-ui-kit-react

Pone las burbujas con cola, el agrupado de mensajes seguidos, los separadores
de dia y la lista de conversaciones.

## Los colores

Los del WhatsApp Web actual en modo oscuro. Estan en `pages/chat.css`.

## Aviso sobre la marca

La licencia MIT cubre el codigo de esos autores, **no la identidad visual de
Meta**. Para una herramienta interna es lo habitual; si esto se vende como
producto o se usa en marketing, es una conversacion aparte y ninguna licencia
de software la resuelve.
